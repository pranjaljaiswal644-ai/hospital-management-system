# hospital-management-system
The Hospital Management System is a simple Python-based project designed to manage basic hospital activities such as patient registration, doctor information, appointments, and patient records.
This project is developed as a first-year Python programming project using basic programming concepts.
## Objectives
1. To register and manage patient details.
2. To store patients information.
3. To manage appointments.
4. To maintain basic patient records.
5. To provide a simple and easy-to-use hospital management system.
## Features
1. Patient Registration
2. Patient Record Management
3. patient Information
4. Appointment Management
5. View Patient Details
6. Simple Menu-Based Interface
7. Easy-to-use Python program
## Technologies Used
1. Programming Language: Python
2. Concepts Used: Variables, Input/Output, Conditional Statements, Loops, Lists, Dictionaries, Functions
3. IDE: VS Code / IDLE / PyCharm
4. Version Control: Git and GitHub

## Requirements
Before running the project, make sure Python is installed on your computer.
Check Python installation using:
python --version
## Installation and Setup
Step 1: Clone the Repository
git clone YOUR_GITHUB_REPOSITORY_LINK
Step 2: Open the Project Folder
cd Hospital-Management-System
Step 3: Run the Python Program
python hospital_management.py
## How to Use
After running the program, a menu will be displayed.
The user can select options such as:
1. Register Patient
2. View Patient Details
3. Add patien
4. Book Appointment
5. View Appointments
6. Exit
Enter the required option and provide the requested information.
